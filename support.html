Support

Quick fixes for multiplayer, purchases, local progress and audio.

Game Center / Quick Match

  • Make sure you are signed in to Game Center in iOS Settings.
  • Use a stable internet connection and keep MYTHIC CONCLAVE in the foreground while matchmaking.
  • Both players must be using compatible versions and the same matchmaking rules mode.
  • If Game Center reports that the app is not recognised or configured, update to the latest App Store/TestFlight build and try again after Game Center configuration has propagated.

Nearby multiplayer

  • Both devices should be nearby, unlocked and running MYTHIC CONCLAVE in the foreground.
  • Allow Local Network access when prompted.
  • Use the same game rules on both devices.
  • If discovery fails, close and reopen the game on both devices and try again.

Coins and In-App Purchases

  • Purchases are processed by Apple through the App Store.
  • After a successful Coin purchase, allow a moment for the balance to update.
  • If payment succeeds but Coins do not appear, fully close and reopen the game before attempting another purchase.
  • Coin packs are consumable purchases and are not restored in the same way as permanent non-consumable purchases.

Progress and backups

Game progress is stored locally on your device. If you use the in-game backup export feature, keep the exported file somewhere safe. Importing a backup may replace current progress after confirmation. Deleting the app may remove local progress.

Audio and Silent Mode

MYTHIC CONCLAVE respects iPhone Silent Mode. When Silent Mode is enabled, game music, sound effects and cinematic audio are intended to remain silent. If audio behaves unexpectedly, confirm the device is actually in Silent Mode, then relaunch the app.
